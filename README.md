## 🚀 **Featured Project**

### 1️⃣ Loan Default Prediction (HMEQ Dataset)  
**Goal:** Predict loan default likelihood to support better credit risk management and minimize false negatives.  
**Tools:** Python (Pandas, Scikit-learn, NumPy, Matplotlib), Logistic Regression, Random Forest, XGBoost  
**Highlights:**  
- Conducted data imputation using KNN and SimpleImputer for missing values.  
- Scaled continuous variables and created new ratio features to improve performance.  
- Tuned thresholds and hyperparameters to maximize recall (identify more defaults).  
- Evaluated models using confusion matrix, ROC-AUC, and F2-score.  
- Visualized key variable relationships and feature importance.
